# care_maternal

Maternal care plugin for CARE: pregnancy-to-postpartum checks that doctors can edit, check priorities with
reminders to staff on duty, a Maternal patient tag and worklist, booking at a chosen time, no-show handling with
ASHA home visits, an Eka Care scribe token proxy, and referrals between hospitals.

- [README](../README.md): what it does, the API, settings, commands, tests and known limits.
- [DEMO.md](../DEMO.md): a step-by-step test runbook for the live hospitals.
- [DEMO-HANDOVER.md](../DEMO-HANDOVER.md): the two-hospital deployment, how to deploy a change, and the referral stories.
- [HISTORY.md](../HISTORY.md): what changed in each version.
